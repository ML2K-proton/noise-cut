Recommendation

  • Use DFN3 as an opt-in high-quality mode; keep RNNoise as the default and fallback.
  • Do not add the 80 Hz high-pass to the DFN3 path; raw DFN3 was more consistent.
  • Expect babble, wind, and construction to leak; DFN3 is not a BVC/AEC replacement.
  • Runtime package is about 25 MB installed; model load is about 150 ms.
